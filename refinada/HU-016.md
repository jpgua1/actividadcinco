# Edición de Perfil de Usuario

## Historia de Usuario
> Como **usuario registrado**, quiero **editar mi información personal y cambiar mi foto de perfil** para **mantener mis datos actualizados y personalizar mi cuenta**.

## Criterios de Aceptación

### AC1 – Edición de Información Personal
- **Dado** que el usuario está autenticado y accede a la sección de perfil
- **Cuando** edita campos como nombre, correo electrónico o teléfono y guarda los cambios
- **Entonces** la información se actualiza correctamente y se muestra un mensaje de confirmación

### AC2 – Cambio de Foto de Perfil
- **Dado** que el usuario está en la sección de edición de perfil
- **Cuando** selecciona una nueva imagen y la sube como foto de perfil
- **Entonces** la foto se actualiza y se muestra la nueva imagen en el perfil del usuario

### AC3 – Validaciones de Datos
- **Dado** que el usuario ingresa información en los campos de edición
- **Cuando** los datos no cumplen con el formato requerido (por ejemplo, email inválido o imagen no soportada)
- **Entonces** se muestra un mensaje de error y no se permite guardar hasta corregir los datos
