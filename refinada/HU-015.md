# Recuperación de contraseña por correo electrónico

## Historia de Usuario
> Como **usuario que olvidó su contraseña**, quiero **poder recuperarla por email** para **volver a acceder a mi cuenta**.

## Criterios de Aceptación

### AC1 – Solicitud de recuperación de contraseña
- **Dado** que el usuario está en la pantalla de inicio de sesión
- **Cuando** selecciona la opción "¿Olvidaste tu contraseña?" e ingresa su correo electrónico registrado
- **Entonces** el sistema muestra un mensaje indicando que se ha enviado un correo de recuperación si el email está registrado

### AC2 – Envío de correo de recuperación
- **Dado** que el usuario ha solicitado la recuperación de contraseña con un correo válido
- **Cuando** la solicitud es procesada
- **Entonces** el sistema envía un correo con un enlace seguro para restablecer la contraseña

### AC3 – Restablecimiento de contraseña
- **Dado** que el usuario recibe el correo de recuperación
- **Cuando** hace clic en el enlace y accede a la página de restablecimiento
- **Entonces** puede ingresar y confirmar una nueva contraseña, y el sistema actualiza la contraseña permitiendo el acceso con las nuevas credenciales

## Notas Técnicas
- **Dependencias:** Servicio de correo electrónico, base de datos de usuarios
- **Riesgos:** Posibles intentos de phishing, manejo seguro de enlaces de restablecimiento
- **Consideraciones de seguridad:** El enlace de recuperación debe expirar tras un tiempo definido y ser de un solo uso; las contraseñas deben almacenarse de forma segura (hashing)
- **APIs / Servicios externos:** Servicio SMTP o proveedor de email (ej. SendGrid, Amazon SES)
