# Visualización del Historial de Pedidos

## Historia de Usuario
> Como **usuario registrado**, quiero **ver mis pedidos anteriores** para **hacer seguimiento de mis compras**.

## Criterios de Aceptación

### AC1 – Acceso al historial de pedidos
- **Dado** que el usuario está autenticado en la plataforma
- **Cuando** accede a la sección "Historial de pedidos" desde el menú de usuario
- **Entonces** se muestra una lista de todos sus pedidos anteriores con fecha, estado y total de cada pedido

### AC2 – Detalle de pedido
- **Dado** que el usuario visualiza la lista de pedidos anteriores
- **Cuando** selecciona un pedido específico
- **Entonces** se muestra el detalle del pedido, incluyendo productos, cantidades, precios, dirección de envío y estado del pedido

### AC3 – Actualización en tiempo real del estado del pedido
- **Dado** que el usuario consulta el historial de pedidos
- **Cuando** el estado de un pedido cambia (por ejemplo, de "En proceso" a "Enviado")
- **Entonces** el estado se actualiza automáticamente en la interfaz sin requerir recarga manual

## Notas Técnicas
- **Dependencias:** Servicio de autenticación, API de pedidos
- **Riesgos:** Posible inconsistencia en el estado de pedidos si la API no soporta actualización en tiempo real
- **Consideraciones de seguridad:** Asegurar que solo el usuario autenticado pueda ver su propio historial
- **APIs / Servicios externos:** API de gestión de pedidos, servicio de autenticación
