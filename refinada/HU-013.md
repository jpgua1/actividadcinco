# Pago seguro con tarjeta de crédito

## Historia de Usuario
> Como **usuario**, quiero **poder pagar mis productos con tarjeta de crédito de forma segura** para **completar mi compra y asegurar la protección de mis datos personales y financieros**.

## Criterios de Aceptación

### AC1 – Validación de datos de tarjeta
- **Dado** que el usuario está en el checkout y selecciona tarjeta de crédito como método de pago
- **Cuando** ingresa los datos de la tarjeta (número, fecha de expiración, CVV, nombre)
- **Entonces** el sistema valida que los datos sean correctos y muestra mensajes de error claros si hay algún dato inválido

### AC2 – Procesamiento seguro del pago
- **Dado** que los datos de la tarjeta han sido validados correctamente
- **Cuando** el usuario confirma el pago
- **Entonces** el sistema procesa la transacción de forma segura, utilizando un proveedor de pagos certificado, y no almacena datos sensibles de la tarjeta

### AC3 – Confirmación de pago exitoso o fallido
- **Dado** que el pago ha sido procesado por el proveedor
- **Cuando** la transacción es aprobada o rechazada
- **Entonces** el usuario recibe una notificación clara del resultado (éxito o error), y en caso de éxito, se genera el comprobante de compra

## Notas Técnicas
- **Dependencias:** Integración con proveedor de pagos (ej. Stripe, MercadoPago)
- **Riesgos:** Fallos en la integración, posibles rechazos de tarjetas, cumplimiento de PCI DSS
- **Consideraciones de seguridad:** Encriptación de datos, no almacenamiento de información sensible, cumplimiento de normativas
- **APIs / Servicios externos:** API del proveedor de pagos
